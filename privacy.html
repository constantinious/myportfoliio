Privacy Policy

Greek Cities Uploader · Last updated 25 October 2026

Greek Cities Uploader is a personal tool run by Konstantinos Gkekas. It uploads the weekly "Greek Cities in 3D" videos to his own YouTube channel through the YouTube API Services. It is not offered to anyone else, and only the channel owner signs in to it.

What it accesses

With the channel owner's consent, the tool uses the YouTube Data API to upload videos, set their titles, descriptions, thumbnails and scheduled publish times, and add them to a playlist on that channel. It does not read, collect or store data about any other user.

How credentials are stored

The OAuth refresh token is stored as an encrypted secret in a private GitHub repository and is used only by its scheduled upload job. Nothing is sold, shared with third parties or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page. By using YouTube through this tool you are also bound by the YouTube Terms of Service and the Google Privacy Policy.
