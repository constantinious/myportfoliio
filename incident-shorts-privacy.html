Privacy policy

Effective October 25, 2026. This policy covers incident-shorts, a personal tool that uploads videos to its owner's YouTube channel.

What the app accesses

incident-shorts uses the YouTube Data API with one permission: uploading videos (youtube.upload). It uses it only to upload videos that the owner made to the owner's own channel. It does not read, change or delete other videos, comments, subscribers, messages or any other account data.

What is stored

The app stores one OAuth refresh token, kept as an encrypted secret, so that it can upload without a new sign-in each time. It stores the IDs of the videos it uploaded. It collects no personal data from viewers or other users and shares nothing with third parties.

YouTube and Google

incident-shorts uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time on the Google account's third-party connections page. After that, the stored token stops working and is deleted.
